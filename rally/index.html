FieldRoutes connection

Your office's API credentials — FieldRoutes support issues a key + token per office (support@fieldroutes.com). Stored only on this device. The live connector that pushes customers automatically ships next; until then, use Export.

Map

Apple Maps is the intended RALLY map: Apple satellite imagery under RALLY's own territories and pins. It needs a MapKit JS token from your Apple Developer account — a signed key the office pastes here. Without one, RALLY uses the offline-capable map instead, which keeps working with no signal.

The token is a credential. It is stored only on this device and is never written to a backup, a log or the team server.

Google map imagery

The map is always Google — vivid satellite imagery with Google's street labels, powered by the office's built-in key. Paste a different key below only to override it on this device (your Google project needs the Map Tiles API enabled).

Stored only on this device. Clear the field to go back to the office key.
